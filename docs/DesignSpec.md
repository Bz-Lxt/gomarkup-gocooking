# GoCooking Design Spec

> 视觉方向：**湿市场晨光** —— 清晨摊位刚揭开油布，竹筐还带着露水，小票用油纸包着。

## 气质

不是健康餐 App 的薄荷绿，也不是外卖红。这是一张能被油点溅到、却仍然体面的买菜手册。温暖、具体、有手感。

## 色板

| Token | Hex | 用途 |
|---|---|---|
| `--paper` | `#F4EDE1` | 页面底，仿草纸 |
| `--ink` | `#2A2118` | 主文字 |
| `--terracotta` | `#C45C26` | 主操作、今日高亮 |
| `--leaf` | `#3F6B4A` | 成功、叶菜、勾选 |
| `--clay` | `#E8D2B5` | 卡片、槽位空态 |
| `--soot` | `#5C5146` | 次级文字 |
| `--chili` | `#B33A2B` | 危险、过期 |
| `--yolk` | `#E0A43A` | 临期、警告 |

禁止紫色渐变、禁止 Inter / Roboto。

## 字体

- 标题：**Noto Serif SC**（衬线，像菜市场价牌）
- 正文 / UI：**Noto Sans SC**
- 数字（份数、数量）：`tabular-nums`，字距收紧

## 布局

- 全宽主区（`w-full`），禁止页面级 `max-w-*`
- 登录是唯一居中卡片例外
- 断点：768 收起侧栏为抽屉；480 日历改为纵向 7 行

## 组件

- 菜谱卡：圆角 14px，左侧 6px 陶土条，拖拽时旋转 2° + 阴影
- 餐位槽：虚线陶土框，悬停时叶绿色
- 清单项：大方复选框（22px），勾选后删除线 + 叶绿色
- Toast：右上角纸片，可手动关闭，5s 消失
- Dialog：自定义模态，禁止 `alert/confirm`
- Select：自定义箭头 SVG，禁止原生 appearance

## 动效

- 进入：纸张错落落下（stagger 40ms）
- 拖拽：只做 transform，保证 ≥50 FPS
- 清单勾选：复选框弹性 scale 一次
